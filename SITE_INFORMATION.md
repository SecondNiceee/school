# School - Образовательная платформа

## О проекте

Это образовательная платформа, построенная на современном стеке **Next.js 16** + **PayloadCMS 3.80**. Проект предназначен для организации учебного процесса: управления учениками, тестирования, загрузки материалов.

## Технологии

- **Next.js 16** - React фреймворк с App Router
- **PayloadCMS 3.80** - Headless CMS для управления контентом
- **PostgreSQL** - База данных (через @payloadcms/db-postgres)
- **TailwindCSS 4** - Стилизация
- **TypeScript** - Типизация

## UI Компоненты

Все переиспользуемые UI компоненты находятся в `/components/ui`. При создании новых компонентов сначала проверьте, нет ли подходящего в этой директории.

## Коллекции данных

### Users (Ученики)
- `name` - Имя
- `email` - Email
- `passwordHash` - Хеш пароля
- `isVerified` - Подтверждена ли почта

### Admins (Преподаватели)
- `name` - Имя
- `email` - Email
- `passwordHash` - Хеш пароля

### Tests (Тесты)
- `title` - Название
- `description` - Описание
- `questions` - Массив вопросов (choice/text)
- `assignedTo` - Назначенные ученики

### TestResults (Результаты тестов)
- `test` - Связь с тестом
- `student` - Связь с учеником
- `answers` - Ответы ученика (JSON)
- `score` - Количество правильных
- `percentage` - Процент правильных

### Materials (Материалы)
- `title` - Название
- `description` - Описание
- `fileUrl` - URL файла
- `assignedTo` - Назначенные ученики

## Основные функции

1. **Для учеников** (`/lk`):
   - Просмотр назначенных материалов
   - Прохождение тестов (компонент `TestTaker.tsx`)
   - Просмотр результатов и ошибок (компонент `TestResultViewer.tsx`)
   - Фильтрация ответов: все / только ошибки

2. **Для преподавателей** (`/new-admin`):
   - Управление учениками (`StudentsTab.tsx`)
   - Создание и назначение тестов (`TestsTab.tsx`)
   - Загрузка учебных материалов (`MaterialsTab.tsx`)
   - Просмотр результатов тестов учеников (`StudentTestsList.tsx`, `AdminTestResultViewer.tsx`)
   - Детальный разбор ответов с отображением ошибок

## Компоненты тестирования

### Для учеников
- **`TestResultViewer.tsx`** - Просмотр результатов пройденного теста
  - Показывает процент и количество правильных ответов
  - Разбор каждого вопроса с указанием правильного ответа
  - Фильтр "Все" / "Ошибки" для отображения вопросов
  - Кнопка запуска теста если не пройден

### Для администраторов
- **`StudentTestsList.tsx`** - Список назначенных тестов ученика
  - Раскрывающийся аккордеон для просмотра деталей
  - Статус: "Выполнено" / "Ожидает"
  - Количество ошибок
- **`AdminTestResultViewer.tsx`** - Детальный просмотр ответов ученика
  - Показывает ответы ученика и правильные ответы
  - Фильтрация по ошибкам
  - Варианты ответов для вопросов с выбором
